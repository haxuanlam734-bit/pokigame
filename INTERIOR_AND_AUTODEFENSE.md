# HQ Interior + Automated Defense Upgrade

## Added
- Playable 3-floor Command HQ interior.
- Ground-floor security/reception, CCTV screens, armory racks and money-production deck.
- Floor 2 command/intelligence room, tactical table and server racks.
- Floor 3 war room / commander deck and rooftop access.
- Interior stairs with ramp/step visuals and floor-height snapping so the player can physically climb between levels.
- Elevator/lift shaft visuals.
- Interior emergency lighting, cyan/amber strips and service details.
- 12 fixed automated machine-gun emplacements around the military complex.
- Auto turrets acquire the nearest zombie, rotate their gun and fire automatically.
- Damage + tracer effects for automated machine guns.

## Controls
- WASD: move
- SHIFT: sprint
- SPACE: jump
- E: interact with base facilities
- 1: bandage
- 2: medkit

## Notes
- Automated machine guns are part of the base defense network and do not consume player ammo.
- Existing player-built turrets remain available and continue to work alongside the automated network.
- Existing collision logic is preserved for walls/buildings; interior furniture is intentionally decorative/passable.
